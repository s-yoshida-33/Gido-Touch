# Gido Touch (Tauri版)

## 1. 概要

Gido Touch は、大型タッチパネルディスプレイでの運用を想定したインタラクティブなフロアガイド表示システムです。
直感的なマップ操作、店舗検索、デジタルサイネージ機能を提供します。

* **ターゲットOS**: Windows (x64)

## 2. システム構成・技術スタック

Tauriアーキテクチャを採用し、軽量かつ高速な動作を実現しています。

* **Backend**: Rust, Tauri 2.x
* **Frontend**: React 19.2.0, TypeScript, Vite, Tailwind CSS (v4)
* **Map Interaction**: `react-zoom-pan-pinch` (ズーム挙動等の制御)
* **Animation**: Framer Motion

## 3. 機能要件

* **フロアマップ表示・操作**: SVGマップを表示し、店舗ピンを配置、双方向によるスムーズな拡大縮小が可能。
* **店舗リスト・詳細**: 各フロアの店舗一覧を表示し、店舗ピンやリストを選択すると、営業時間、電話番号、写真などの詳細情報をモーダル表示。
* **デジタルサイネージ**: 画面の縦型動画エリアでプロモーション動画などを再生。
* **統合設定画面**: 現在地設定、カスタム画像設定、ドラッグ＆ドロップによる店舗ピンの座標調整が可能。

## 4. 画面仕様

* **メイン画面**: マップエリア（SVGマップ、店舗ピン）、サイドバー/動画エリア（縦型動画再生、店舗リスト）で構成。
* **設定画面**: 通常はメニューバーからアクセスし、変更内容は `userData` (Tauriではローカルデータディレクトリ) の `settings.json` に保存。

## 5. データ構造と設定

設定は `%LOCALAPPDATA%\com.tti.gido_touch\settings.json` （想定パス）に保存されます。
起動フロア(`floor`)、アイコンデザイン(`locationIcons`)、画像パス(`imageSettings`)、店舗座標(`shopPositions`)などを管理します。

## 6. 外部システム連携・通信仕様

継続的なポーリングを廃止し、SSEを利用したプッシュ通知型へ移行することでリアルタイム性を向上させています。

* **BridgeWebPopper (店舗情報)**:
* ポート: `8090 - 8099` で自動検出。
* API/SSE: `/api/shops`, `/api/events`。
* キャッシュ戦略: 初回起動時に全データをメモリキャッシュ。SSEの `update` イベント受信時にAPIから再取得して画面反映。
* 再接続: 切断時は3秒後に自動再接続。


* **WSP (動画・サイネージ)**:
* ポート: `8080 - 8089` で自動検出。
* API/SSE: `/api/current-timeline`, `/api/events`。
* 監視: メイン動画はSSEでリアルタイム更新、右上動画エリアは0.5秒間隔のポーリング監視。
* 音声: ミュートなしで再生（設定から変更可能）。



## 7. ロギング・エラーハンドリング

Rustコマンドを経由したファイルロギングを実装（Gido共通仕様に準ずる）。
トラブルシューティングとして、店舗データ未表示時はポートブロック、動画未再生時はメディアファイルパスの確認が推奨されます。

## 8. 自動アップデート機能

起動時に更新サーバーを確認し、新しいバージョンを自動ダウンロード・適用します。
更新プロセス中は専用の `PatchScreen` が表示されます。

## 9. 開発・ビルド・運用

* **開発起動**: `npm run tauri:dev` (フロントエンドのみは `npm run dev`)
* **ビルド**: `npm run tauri:build`
